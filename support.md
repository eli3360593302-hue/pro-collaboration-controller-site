## Getting help

Use the public GitHub issue tracker for installation problems, documentation
questions, reproducible workflow defects, or privacy enquiries:

[Open a support issue](https://github.com/eli3360593302-hue/pro-collaboration-controller-site/issues)

请只提交复现问题所需的最少信息。不要在公开 issue 中粘贴密码、API key、会话 Cookie、
私人对话全文、未公开研究材料、个人身份信息或付款信息。

## Include

- plugin version;
- ChatGPT or Codex surface used;
- expected behavior and observed behavior;
- a minimal, redacted reproduction;
- whether Pro was selected, unobservable, or unavailable.

The publisher does not provide account recovery, subscription refunds, model
quota changes, or support for OpenAI-operated services. Contact the relevant
service provider for those issues.
